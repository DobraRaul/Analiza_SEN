# Analiza_SEN

Analiza datelor privind Sistemul Energetic Național (SEN) și piețele de energie electrică din România.

Surse de date:
Datele provin din surse publice, inclusiv ENTSO-E Transparency Platform și surse publice privind sistemul energetic din România.
Datele externe sunt utilizate și atribuite conform condițiilor de reutilizare aplicabile surselor respective.
